# 本地工具

运行环境：Python 3.10 或更高版本，仅使用标准库，无需 API 密钥。输出写入工作目录，不写回技能资源目录。

## CSV 数据画像

只读取本地 UTF-8/UTF-8 BOM 的规则 CSV；不直接读取 XLSX、数据库或仪器二进制文件。需要其他格式时，使用实际可用工具导出副本并保留字段含义。

```bash
python scripts/profile_csv.py examples/monitoring.csv --key point_id timestamp --time-column timestamp --missing-token NA --output /your-work/profile.json
```

空白默认按缺测计数；其它缺测编码通过可重复的 `--missing-token` 指定。缺测编码依数据字典决定，不能把真实零值列为缺测。

输出字段的缺测、数值可解析数、非数值与非有限数计数、数值范围；完全重复的多余行数；给定键下的冲突记录位置；时间范围及无法解析的记录。数值可解析不代表该列应当变为数值，`001` 等标识仍是标识。

时间解析要求 ISO 8601 且带时区偏移；未带偏移的时间列为待明确，不猜时区。脚本不检查合并数据的整体排序，因为多个测点可能交错；先按仪器或测点分组再检查顺序。

`source_rows` 是包含表头的逻辑 CSV 记录序号，遇到单元格内换行时不等于文本行号。输出不含逐条原值，但可能包含用户字段名。脚本读取全表到内存，适用于内存可容纳的数据；大型记录应按明确分区处理并报告范围。

工具不改写数据、不推断测点物理状态，也不自动删除冲突记录。样例是合成数据。
