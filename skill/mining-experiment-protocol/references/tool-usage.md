# 本地工具

运行环境：Python 3.10 或更高版本，仅使用标准库，无需 API 密钥。输出写入工作目录，不写回技能资源目录。

## 全因子试验布局

当因素的离散水平已经明确、每个区组能够完成全部组合时使用。脚本不选择最优设计，不实现部分析因、响应面或裂区随机化。

配置包含 `factors`（因素名到水平列表）、`replicates`（每区组内每组合的计划重复数）、`blocks`（按给定顺序执行的区组）及整数 `seed`。因素名可含单位，例如 `water_pct`。每个区组包含全部组合，区组内随机排序；脚本不会将组合拆分到不同区组。

在技能目录运行，或将脚本和输入路径替换为绝对路径：

```bash
python scripts/generate_design.py examples/design.json --output /your-work/planned-runs.csv
```

输出列为 `run_id,block,replicate` 及因素列。输出文件需尚不存在，避免覆盖。最大布局为十万行；更大设计需要专门规划。`replicate` 仅是计划标签，独立试件和有效重复由试验设计决定。相同配置与种子在相同 Python 环境中可复现顺序，保存导出的布局以供使用。

样例为合成的布局演示，水平值不代表任何岩样或仪器的推荐参数。
