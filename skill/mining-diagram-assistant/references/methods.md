# 方法与判断依据

## 绘制方法

### 建立对象与关系

识别需要呈现的对象、分组、连接、方向和注释。区分真实连接与图面交叉、地质接触与推测延伸、实际尺寸与示意间距。不同材料描述冲突时，先保留问题，不为了图面完整自行补造关系。

### 按图种组织信息

- **采场与巷道布置**：突出开采范围、巷道连接、开挖阶段及研究区域。
- **地质剖面**：核对剖切方向、层序、断层、倾向与高程，区分实测和推测部分。
- **通风关系**：突出节点、风流方向与设施，避免交叉线产生误连；网络图本身不表示已完成风量计算。
- **监测点布置**：保证点号清楚、位置有依据，必要时用局部放大解决密集标注。
- **工艺或研究过程**：用明确的阶段和输入输出关系表达，避免加入与主题无关的工程背景。

### 选择表达与工具

需要精确关系和后续编辑时，优先使用 SVG、draw.io 或可复现绘图代码；流程关系可使用 Mermaid。用户需要 CAD 格式时，结合实际可用工具和原图格式处理。

按比例绘制需要可靠几何和坐标；比例不一致或垂直夸大要明确标示。概念示意不放入貌似精确的比例尺。需要三维效果时，保证透视不会掩盖层位、连接或尺寸含义。

### 完成图面与核验

用颜色、线型、线宽和留白区分对象层级；同类对象保持一致。图例解释符号，图注说明图的范围和必要简化。方位、尺寸和风向依据资料填写，未知项明确表示。

生成图件后检查中文显示、遮挡、裁切、引线、点号及图例，回查关键连接、层序和尺寸。修改时同步更新相关标注和图例，保持源文件与预览一致。


## 进阶判断

### 空间和拓扑不要混用
概念网络中节点位置只为布局服务，不代表实际坐标。图中距离和边长不能解释为工程距离。若存在同名实体或跨层连接，先用对象 ID 区分，再选择平面、剖面或局部放大表达。

### 比例与剖面
平面和剖面的方位参照应一致。断层延伸、地层界面和地下对象的推测段用不同线型。只有某一方向被夸大时，分别标注比例，不使用一个统一比例尺掩盖变形。
