# mining-diagram-assistant

让读者快速看懂工程对象在哪里、如何连接、研究关注什么，同时保留后续修改和复用图件的能力。

## 核心能力

- **从资料到图形结构**：提取地层、巷道、采场和测点之间的空间或连接关系，减少手工梳理。
- **围绕表达目的取舍**：区分用于说明几何、展示过程和突出监测布置的图，保留关键细节。
- **可编辑、可核对**：生成适合修改的图形源文件或绘图代码，并检查标注与工程资料是否一致。

## 确定图要讲什么

确认图的用途、读者和最重要的信息，再读取已有草图、平剖面、坐标、尺寸、连接关系与风格要求。已有图件的修改优先沿用其图例和表达习惯；缺少精确几何时，采用明确的概念示意。

只追问会改变结构的信息，例如视角、关键连接或是否按比例。次要缺项可以在图中标注，先形成可讨论的版本。

## 工作流程

1. 确定图件用途、视角和需要突出的问题，整理对象与连接。
2. 有尺寸时按资料绘制；只有关系时选择明确的非比例示意。
3. 需要简单可编辑布置图时可用本地 SVG 脚本；复杂剖面或 CAD 按原资料选择工具。
4. 渲染后回查关系、标注、图例和未确认信息，再交付源文件。

## 按需使用资源

- 使用本地工具前，阅读 [参数与适用范围](references/tool-usage.md)，再调用 [scripts/render_network.py](scripts/render_network.py)。工具仅处理所说明的格式和能力，不代表完整任务已完成。
- 首次了解输入格式时，查看合成样例 [examples/network.json](examples/network.json)；演示数据不可当作实际测量或规范参数。
- 方法选择、边界判断或复杂情形：阅读 [references/methods.md](references/methods.md)。
- 需要快速组织交付内容时，复制并裁剪 [assets/diagram-brief.md](assets/diagram-brief.md)；这是可选起点，不是固定输出格式。

## 交付

优先交付用户所需的图件及可编辑版本，附简短图注和影响理解的未确认项。图面复杂时，可拆成总图与局部图；简单任务保持单图。不要用文字方案代替本来能够生成的图，也不声称未渲染的代码已通过视觉检查。
