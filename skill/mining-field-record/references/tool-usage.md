# 本地工具

运行环境：Python 3.10 或更高版本，仅使用标准库，无需 API 密钥。输出写入工作目录，不写回技能资源目录。

## 现场文件索引

将本地资料目录作为输入，输出相对路径、字节数、SHA-256 和文件系统修改时间，以及字节相同文件组。

```bash
python scripts/index_evidence.py /your-evidence-folder --output /your-work/evidence-index.json
```

工具递归读取普通文件，跳过符号链接、目录链接和本次输出路径；未能读取或读取时变化的文件单独报告。不会解析照片内容、EXIF 或文档正文，不上传、重命名或修改输入。

输出路径需尚不存在。文件量较大时哈希计算需要读取全部内容，可先对本次授权的资料子目录执行。

相同哈希表示文件字节相同，不是对现场事实的认证。不同哈希可能只是同一图片压缩方式不同；文件修改时间不能替代拍摄或事件发生时间。实际关联仍需结合台账和材料内容。
