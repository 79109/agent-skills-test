# 方法与判断依据

## 分析方法

### 从机制决定建模取舍

明确需要解释的过程与响应，例如开挖卸荷后的位移、结构面控制的滑移、支护受力或渗流变化。结合尺度、结构面和变形特征，判断二维或三维、连续或离散、静力或动力、单场或耦合分析是否适合。

说明哪些地层、结构面和施工阶段需要保留，哪些简化不会改变当前问题的主要判断。不要仅因某个软件熟悉就默认采用它，也不把完整岩样参数直接当成现场岩体参数。

### 审查参数、边界与加载路径

核对几何单位、材料定义、初始应力、地下水、边界约束、开挖顺序及支护激活时机。特别检查压应力正负约定、总应力与有效应力、峰值与残余参数、二维假设和局部坐标之间是否一致。

区分实测、反演、经验估计和假设参数。对缺失的关键参数提出可辨识的范围或补充试验方向；演示取值明确标为演示。

### 先检查数值，再评价工程解释

用适合问题的解析解、基准算例或简化模型检查实现。考察网格、计算域、步长和求解设置对关键响应的影响；不能仅因收敛就认定模型正确。尖角或理想化边界处的局部峰值，应结合网格变化判断是否为数值奇异性。

标定时说明使用了哪些观测和目标量；验证尽可能使用不同的测点、时段或工况。若多个参数组合都能拟合数据，说明参数识别的不唯一性，而不是宣称得到唯一真实参数。

### 围绕决策开展参数分析

先明确待比较的响应，再确定参数范围、关联和计算预算。局部扰动适合检查基准附近的变化；多参数联合变化需要相应采样或试验设计，并考虑交互作用。选择方法时说明它能支持的结论。

对比工况时统一阶段、位置、单位及图形色标。保留失败或不收敛的工况，判断其反映数值问题还是模型适用范围。参数排序只对本次范围和响应有效，不外推为所有工况下的控制因素。


## 进阶判断

### 灵敏度的解释范围
单因素差值描述基准附近的响应，不证明参数独立。若多个参数同时改变，不能把结果差异分配给其中一个参数。无量纲弹性指标在基准参数或响应为零时无定义，应保留有量纲斜率或绝对差。

### 机制与模型形式
出现大变形、结构面张开滑移、明显路径依赖或耦合效应时，先检查模型是否表达这些机制。增加网格密度不能弥补缺失的物理机制。
